# МОК Замер — Android v0.1 (исходный проект)

Прототип Android-приложения для замеров жалюзи. Локальная база SQLite, заказы, клиенты, окна, системы жалюзи, размеры в мм.

## Сборка
1. Установите Android Studio с Android SDK 35 и JDK 17.
2. Откройте папку MOK_Zamer_Android как проект.
3. Дождитесь Gradle Sync (нужен интернет для Android Gradle Plugin).
4. Build > Build APK(s). Полученный APK будет в app/build/outputs/apk/debug/.

Минимальная версия Android 8.0 (API 26). Исходный код Java, без сторонних библиотек приложения.

## Что реализовано
- Создание заказа (клиент, телефон, адрес).
- Добавление окон и выбор типа жалюзи.
- Ввод и проверка размеров в миллиметрах.
- Локальное сохранение заказов и окон (SQLite).

## Что пока НЕ реализовано
- Bluetooth-подключение Bosch GLM 50-27 C.
- Редактирование/удаление записей, фото, PDF, расчёт раскроя и себестоимости.
- Учётные записи, синхронизация и лицензирование.

Приложение — начальный прототип, не проверенный на реальном устройстве. Размеры в нём являются замерами, а не готовыми размерами раскроя. Для производства без проверки технических карт не использовать.
